# UtsavAI — GenAI Celebration & Event Planning Assistant
### PromptWars Virtual • [Challenge 5] Celebration & Event Planner

> **Problem Statement:** Create a GenAI-powered planning assistant that helps users organize weddings, birthdays, and community events with budgets, timelines, vendor checklists, and personalized ideas.

## 🚀 Live Features Built for Challenge #5
1. **Multi-Event AI Architect (`Weddings`, `Birthdays`, `Community Events`)**
   - Pre-loaded with 3 complete scenarios (*Royal Jaipur Palace Wedding*, *Kabir's 25th Neon Rooftop Bash*, and *Jaipur Tech & Indie Makers Fest 2026*) plus a **"+ New AI Event"** wizard that synthesizes a tailored budget, countdown timeline, vendor checklist, and creative ideas for any custom event.
2. **GenAI Event Co-Pilot & Prompt Studio**
   - Works out-of-the-box with a domain-trained Event Reasoning Engine + optional live **Google Gemini 2.5 Flash API** key integration.
   - Includes 1-click action buttons to apply a **15% AI Cost-Saver** directly to the budget or append an **Hour-by-Hour Run-of-Show** to the timeline.
3. **Smart Budget Studio (with Live Chart.js Visuals)**
   - Interactive Target Budget & Guest Count sliders, live per-guest cost calculation, INR (₹) / USD ($) toggle, Planned vs. Actual bar & doughnut charts, and inline editable line items.
4. **Master Timeline & Day-Of Run-of-Show**
   - Filterable Pre-Event Countdown milestones and Event-Day hour-by-hour execution schedule with owner roles and completion progress tracking.
5. **Vendor Checklist & AI Negotiation Playbook**
   - Track vendor quotes, booking statuses (`Shortlisted`, `Negotiating`, `Booked`), contract verification checkboxes, and generate custom **12% Partner Discount Negotiation Scripts**.
6. **Personalized Ideas & Live Digital Invitation Studio**
   - Curated concepts across *Theme & Decor*, *Food & Drinks*, *Entertainment*, and *Favors & Swag* with 1-click **"+ Add to Budget"**, plus a live **SVG Invitation Card Designer** and bilingual WhatsApp invite generator.

## 🛠️ Tech Stack & GenAI Tools Used
- **IDE & Vibe Coding Workflow:** Google Antigravity IDE + Intent-Driven Prompt Engineering
- **AI Engine:** Google Gemini 2.5 Flash API (`generativelanguage.googleapis.com`) + Built-in Domain Reasoning Engine
- **Frontend Stack:** HTML5, Tailwind CSS, Chart.js, Vanilla JavaScript (Zero-build static architecture for instant Vercel deployment)

## ⚡ Deployment Instructions (GitHub + Vercel)
1. Upload `index.html`, `vercel.json`, and `README.md` to a public GitHub repository.
2. Go to [vercel.com](https://vercel.com), click **Add New Project**, and import your GitHub repository.
3. Keep Framework Preset as **Other** and click **Deploy** — your live URL will be ready in ~10 seconds!
